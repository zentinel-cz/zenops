# ZenOps repository instructions

## Living user documentation

- Treat `docs/uzivatelska-prirucka.md` as the canonical ZenOps operating guide.
- Update that guide in the same commit as every user-visible change to roles, permissions, navigation, labels, forms, validation, workflows, record states, filters, exports, audit behavior, or feature availability.
- Do not mark a user-visible change complete until the guide accurately describes the resulting production behavior.
- Keep unfinished functionality explicitly labelled as preparing/incomplete; never document a planned workflow as already available.
- Verify documentation claims against current frontend routes/components and backend authorization before committing.
