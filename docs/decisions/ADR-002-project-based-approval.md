# ADR-002: Project-based Approval

Status: Accepted

Approval authority follows the Project Leader. A WorkDay spanning
multiple projects can therefore require multiple approvers. Only the current
Leader of a Project may approve or return its submitted WorkEntries. Leader and
Admin accounts do not create WorkDays, so no separate self-approval exception
or Admin fallback exists.

ADR-010 governs Admin-only audited Leader replacement and scoped corrections. Historical approval authors remain unchanged.
